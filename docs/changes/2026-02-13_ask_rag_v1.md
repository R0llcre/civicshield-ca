# 2026-02-13 — Ask RAG v1 (gpt-5-mini + file_search + authoritative web_search fallback)

Owner: Codex

## Why

- Ask needs RAG grounding to reduce hallucinations and ensure answers cite authoritative sources for CA-focused immigration + credential verification + legal aid.
- GPT-5 series requires request-parameter changes (no `temperature/top_p/logprobs`), so we must update our OpenAI client accordingly.

## What Changed

### Knowledge base (local RAG corpus)
- `rag/kb/reg_verification.md`
- `rag/kb/legal_aid.md`
- `rag/kb/scam_safety.md`

### Web (Ask backend)
- `apps/web/src/server/env.ts`
  - default model: `gpt-5-mini`
  - new env vars: `OPENAI_VECTOR_STORE_ID`, `OPENAI_ENABLE_WEB_SEARCH`, `OPENAI_WEB_SEARCH_EXTERNAL`, `OPENAI_RAG_STRICT`
- `apps/web/src/server/openai.ts`
  - GPT-5 request shape: uses `reasoning.effort`, `text.verbosity`, `max_output_tokens`
  - RAG tool calls:
    - primary: `file_search` with `vector_store_ids`
    - fallback: `web_search` constrained to allowlisted domains
  - `tool_choice="required"` to ensure retrieval happens
- `apps/web/src/app/api/ask/route.ts`
  - requires `OPENAI_VECTOR_STORE_ID`
  - strict mode: if no allowlisted citations, returns refusal template (or runs authoritative web_search fallback)
- `apps/web/src/app/api/meta/health/route.ts`
  - adds non-secret diagnostics: `ask_configured`, `rag_configured`, `web_search_enabled`, `rag_strict`, etc

### Tests
- `apps/web/src/app/api/ask/route.test.ts`
  - asserts request has tools/tool_choice and does not send `temperature`
  - covers strict web_search fallback behavior

### Ops scripts (repeatable)
- `scripts/rag_sync_openai_vector_store.mjs`
  - bundles `rag/kb/*.md` and syncs into an OpenAI Vector Store (outputs `.tmp/openai_vector_store_id.txt`)
- `scripts/azure_staging_deploy_web.sh`
  - builds/pushes image to ACR and updates Azure Container App
- `scripts/azure_staging_enable_ask_rag.sh`
  - sets OpenAI secret + RAG env vars on Azure staging and verifies `/api/ask`
- `scripts/azure_staging_set_openai_secret.sh`
  - deprecated wrapper -> forwards to `azure_staging_enable_ask_rag.sh`

### Docker hygiene
- `.dockerignore`
  - excludes `.next`, `node_modules`, build outputs, `.tmp`, etc to avoid stale builds and shrink ACR build context

### Docs
- `docs/ENGINEERING_CHECKLIST.md`
- `docs/changes/TEMPLATE.md`
- `docs/RUNBOOK_AZURE.md`
- `README.md` (env vars updated for Ask RAG)

## Rollback / Recovery

### Web (Azure Container Apps)

```bash
az containerapp revision list -g rg-regshieldca-stg-westus2 -n ca-regshieldca-web-stg -o table
az containerapp revision activate -g rg-regshieldca-stg-westus2 -n ca-regshieldca-web-stg --revision <REVISION_NAME>
```

### Disable Ask quickly

Unset env vars on the Container App (or set `OPENAI_RAG_STRICT=true` and remove vector store id):
- `OPENAI_API_KEY` (secretref)
- `OPENAI_VECTOR_STORE_ID`
